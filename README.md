# Groundtruth911 NENA Schema Converter

The Groundtruth911 NENA Schema Converter is a free ArcGIS Pro toolbox for converting NG9-1-1 GIS data between supported NENA GIS Data Model versions.

This repository is for the public beta of the converter only.

## Public beta release

Current release: **v0.9.0-rc1**

Download this file from the **Releases** section of this repository:

`Groundtruth911-NENA-Schema-Converter-v0.9.0-rc1.zip`

Do not use GitHub's automatically generated **Source code** ZIP. The converter is provided as the named release file above.

## Before you begin

- Use a copy of your GIS data. Do not test against your only production copy.
- Review [TESTER-GUIDE.md](TESTER-GUIDE.md) before running the converter.
- Do not post datasets, credentials, personal information, or protected information in a public GitHub issue.
- This is beta software. Review the output before using it in another workflow.

## Quick start

1. Open the repository's **Releases** section.
2. Open release **v0.9.0-rc1**.
3. Under **Assets**, download `Groundtruth911-NENA-Schema-Converter-v0.9.0-rc1.zip`.
4. Extract the ZIP to a local folder.
5. Open ArcGIS Pro and add the included toolbox from the **Catalog** pane.
6. Follow the instructions included with the release and test with copied data.
7. Review the converted output.
8. Share your results through the repository's **Issues** tab.

## Give feedback

Open **Issues**, select **New issue**, and choose:

- **Beta tester feedback** for general results and suggestions.
- **Bug report** when something failed or produced an unexpected result.

Please describe the data structure without attaching the data itself. Include your ArcGIS Pro version, Windows version, source model version, target model version, and the steps you followed when possible.
